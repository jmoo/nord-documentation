######################################################

Nord Electro 5 system settings file (extension ne5s)
File is 78 bytes: 44-byte header + 34-byte body.

The instrument holds exactly one settings file. It carries the System, MIDI and
Sound menus, plus the selection the instrument restores at power-up (mode,
program, Live slot, song). Nord Sound Manager exports it as Settings.ne5s, and a
full backup (ne5b) carries it as Settings/Settings/Settings.ne5s.

Offsets below are for this 78-byte file. Older files use the 24-byte legacy
header (see File format below): the body is the same 34 bytes starting at 0x18
instead of 0x2c, so subtract 0x14 from every body offset.

######################################################

Clavia ID
Offset in file 0x00 to 0x03
ascii C B I N (0x43 0x42 0x49 0x4E)

File format
Offset in file 0x04 to 0x07 (little endian)
0 = legacy header: no 0x18 to 0x2b block, body at 0x18, CRC-16 at end of file
    (60-byte file, see note)
1 = header with checksum (written by Nord Sound Manager 7.40 and later)

Note: a format 0 file drops the checksum at 0x18 and the 16 unused bytes at
0x1c to 0x2b, so the body starts at 0x18, and it adds a 2-byte checksum at the
very end of the file: CRC-16 (CCITT-FALSE parameters: poly 0x1021, init 0xFFFF)
over every byte before it, little endian. The factory Settings.ne5s (OS 1.44) is
this format.

NE5 Settings file ID
Offset in file 0x08 to 0x0b
ascii n e 5 s (0x6E 0x65 0x35 0x73)

Bank
Offset in file 0x0c to 0x0d (little endian)
always 0

Location
Offset in file 0x0e to 0x0f (little endian)
always 0

Unused
Offset in file 0x10 to 0x13
always 0xFFFFFFFF

Settings version
Offset in file 0x14 to 0x17 (little endian)
always 0 on every file seen

Checksum
Offset in file 0x18 to 0x1b (little endian)
CRC-32 (ISO-HDLC / zlib) over 0x2c to 0x4d inclusive

Unused
Offset in file 0x1c to 0x2b
always 0

######################################################

Settings version, repeated in the body
Offset in file 0x2c to 0x2d (big endian)
same value as the header field at 0x14, so always 0

######################################################
Power-up selection 0x2e to 0x30

These are not menu settings. They are where the instrument was, and what it
returns to when switched on. Each keeps the last selection of its own mode, so
for example the Live slot is kept while Live mode is off.

Set List mode
Offset in file 0x2e (b7)
0 = OFF
1 = ON
Note: inferred from the files, not confirmed at the panel. The one file taken in
set list mode has it set, while other files have a different song selected with
it clear, so it follows the mode rather than the song.

Live mode
Offset in file 0x2e (b6)
0 = OFF
1 = ON

Unknown
Offset in file 0x2e (b5)
always 0 on every file seen

Live slot
Offset in file 0x2e (b4-b3)
0 = Live 1
1 = Live 2
2 = Live 3
3 = never seen

Program
Offset in file 0x2e (b2-b0) and 0x2f (b7-b2)
9-bit program location, counted straight through the program banks, the same
way the song file counts them:

    value = (program bank - 1) * 50 + (program location - 1)

so 0 = program 1:1, 49 = program 1:50, 50 = program 2:1 . . . 399 = program 8:50.

Song
Offset in file 0x2f (b1-b0) and 0x30 (b7-b2)
8-bit song location, counted the same way over the 4 song banks:

    value = (song bank - 1) * 50 + (song location - 1)

so 0 = song 1:1 . . . 199 = song 4:50.
Note: inferred from the files, not confirmed at the panel.

Global channel

0 = channel 1, 1 = channel 2 . . . 15 = channel 16
16 = Off

Lower part receive channel

Upper part receive channel
Offset in file 0x3b (b4-b0)
0 = channel 1, 1 = channel 2 . . . 15 = channel 16
16 = Off

Upper split channel
Offset in file 0x3c (b6-b2)
0 = channel 1, 1 = channel 2 . . . 15 = channel 16
16 = Off

Transpose MIDI at
Offset in file 0x3d (b6)
0 = MIDI In

not stored in this file (see note at the end)

System menu

Sustain pedal type
Offset in file 0x31 (b4-b3)
0 = Auto
1 = Closed
2 = Open

Control pedal type
Offset in file 0x31 (b2-b0)
0 = Roland EV-7
1 = Yamaha FC-7

4 = Boss FV-500L
5 = Fatar SL

Rotary pedal type
Offset in file 0x32 (b3-b2)
0 = Closed
1 = Open
2 = Half Moon

Rotary pedal mode
Offset in file 0x32 (b1)
0 = Hold
1 = Toggle

Fine tune
Offset in file 0x32 (b0) and 0x33 (b7-b2)
0 = -50 cents . . . 50 = 0 . . . 100 = +50 cents
Note: -50, 0, +5 and +50 were captured, and -50, 0 and +5 were written back to
the instrument and measured as that many cents of pitch change. The values in
between follow the same scale but were not each captured.

Global transpose
Offset in file 0x34 (b3-b0)
0 = -6 . . . 6 = 0 . . . 12 = +6 (semitones)

B3 trig mode
Offset in file 0x3a (b2)
0 = Normal
1 = Fast

Output routing
Offset in file 0x3c (b7)
0 = Stereo
1 = Lower left / Upper right

Sustain pedal mode
Offset in file 0x3c (b1-b0)
0 = Sustain
1 = Sustain + Rotor Hold
2 = Sustain + Rotor Toggle

Control pedal gain
Offset in file 0x3d (b5-b2)
0 = 1, 1 = 2 . . . 9 = 10
(stored one less than the panel shows)
Note: 1 and 10 were captured; 2 to 9 are assumed to follow the same scale.

Memory Protect
not stored in this file (see note at the end)

######################################################

Note: every setting in the instrument's System, MIDI and Sound menus is in this
file except two. Memory Protect (System) and Local Control (MIDI) are not stored
here at all: toggling either one on the panel,
checked on the display, and reading the settings back changes no bit of the file.
They are kept somewhere else on the instrument, so they are absent from the
file, not undecoded.

Note: each setting above was found by changing that one setting on the panel and
reading the file back; the change moves exactly the bits listed and nothing else.
Where a range goes past the values that were captured, the entry says so.
